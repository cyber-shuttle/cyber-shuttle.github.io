# VS Code tutorial

This tutorial installs CS Bridge, opens VS Code on remote hardware, and stops it again. The hardware is a compute
node of an HPC cluster (Nexus, TTU HPCC, NCSA Delta, PSC Bridges-2 or SDSC Expanse) or a cloud VM on CloudBank
(AWS). Choose yours in any tab; the tabs of every step follow.

On a cluster, CS Bridge submits a Slurm job that runs on a compute node, as [How it works](./index.md#how-it-works)
describes. On CloudBank, it launches an EC2 instance in your AWS account instead. Names such as `jdoe` and `abc123`
are examples; use your own.

## Before you start

You need VS Code 1.101 or newer and an OpenSSH client with an existing `~/.ssh` folder. On an HPC cluster, you also
need a free Microsoft account for the Dev Tunnel, and usually a Slurm account: the allocation your jobs are charged
to.

## 4. Create a session

A **session** is a saved set of resources: on a cluster, a Slurm job request; on CloudBank, a VM. Creating one
starts nothing; each **Start** submits a new job or starts the VM.

<Tabs groupId="site" queryString="site">

<TabItem value="nexus" label="Nexus" default>

Click **+** → **Create New Session** and pick `nexus`.

CS Bridge logs in to read your Slurm accounts and the cluster's partitions; the card shows
`Fetching runtime details…`. Nexus shows a CILogon link, a code and a QR code in an **SSH Authentication** tab. Open the link or scan
the code, sign in with your institution, check that the page shows the same code, then press Enter in the tab:

![The SSH Authentication tab showing the CILogon sign-in link, the code and a QR code for Nexus](/img/screenshots/vscode-tutorial/nexus-auth-device-light.png)
![The SSH Authentication tab showing the CILogon sign-in link, the code and a QR code for Nexus](/img/screenshots/vscode-tutorial/nexus-auth-device-dark.png)

**Add**; CS Bridge checks the request with `sbatch --test-only` before saving it.
